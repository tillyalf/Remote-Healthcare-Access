# Remote Healthcare Access

Welcome to my first project, I will be investigating how machine learning and geospatial analysis can be utilised to identify communities that face greater barriers in accessing healthcare. 

This investigation will be executed at a community level, with a clear focus on not predicting or seeking out health outcomes or PII. Rather using this project to expose current inequalities present in geographic areas. 

Healthcare access, particularly in Aboriginal communities, is significantly more complex then physical distance alone. This project therefore places a core focus on identifying patterns, gaps, and contributing factors, instead of mathematically determining healthcare access. This is especially important in the consideration of the National Aboriginal Community Controlled Health Organisation (NACCHO). NACCHO represents 148 Aboriginal Community Control Health Organisaitons (ACCHOs) which provide culturally informed, community-led healthcare. Considering this, these organisations will be highlighted as an entirely separate factor instead of being generalised with Geographic accessibility measurements.

### Two Main Sections to This Project:
- Part A: Descriptive and Geospatial: This will utilise mapping and data analysis to investigate healthcare accessibility across communities based on key contributing factors such as geographical distance, socioeconomic disadvantage, and the presence of ACCHOs.
- Part B: Machine Learning and Research: This will develop a machine learning model to classify community-level accessibility, and then discover which factors are more strongly associated with communities experiencing greater barriers with healthcare access.
